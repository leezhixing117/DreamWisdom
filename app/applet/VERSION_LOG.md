# 版本歸檔記錄 (Version Snapshot Registry)

## 📌 版本A (Version A) - 基線版本 (Baseline)
- **建立時間**: 2026-09-29
- **Git 標籤 (Tag)**: `version-a`
- **Git Commit**: `e269a22`
- **實體快照目錄**: `.version_backups/version_a/`
- **核心特徵與功能狀態**:
  1. **主頁純淨化**：首頁（`HomeView`）完全不包含夢境星盤，亦無星盤快速導航連結。
  2. **付費會員專區專屬**：
     - 在「方案（付費專區）」頁面中，設立「👑 付費會員尊享專區 · 潛意識天體星盤」專屬卡片。
     - 在「解夢工作台（App）」及左側選單中，增設「👑 尊享星盤」分頁。
  3. **撥動星盤特權嚴格限制**：
     - 只有付費會員（VIP / 管理員）可以點擊「✦ 撥動星盤 · 隨機感應今日潛意識」進行感應與旋轉。
     - 一般會員或未登入訪客點擊時會被鎖定並提示升級付費會員，無法撥動星盤。

### 🔄 回到版本A指令（Revert to Version A）
若任何時候需要返回版本A，只要在對話中提出「返到版本A」或「回到版本A」，即可立即透過：
1. `git checkout version-a -- .`
或
2. 從 `.version_backups/version_a/` 複製覆蓋所有檔案，立即 100% 恢復至此狀態。

- **核心特徵與重大升級狀態**:

     - 解夢選物店（`ProductStoreView`）每種產品及分類皆配備獨立專屬色彩，一眼即能辨認產品類別：

       - ☕ **珊瑚玫瑰紅（Rose / Coral / Warm Tea）**：有機晚安洋甘菊纈草舒緩茶 / 睡前溫潤儀式
